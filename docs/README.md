# MotionSim

## Hardware reference

Open [motionsimbot-reference.html](./motionsimbot-reference.html) for the ESP32-S3 motor, feedback, AS5600, startup, and safety wiring reference.

## GitHub Pages

This is a static site: no build command, backend, or environment variables are required. In the repository settings, enable Pages with **Deploy from a branch**, select the branch, and choose `/docs` as the folder. The reference page will be available at:

`https://<user>.github.io/<repository>/motionsimbot-reference.html`
